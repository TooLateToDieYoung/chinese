# 古詩與樂府詩

> 本頁所說的「古詩」，主要採狹義用法，指近體詩形成後與之相對的「古體詩」，不是泛指所有古代詩歌。樂府詩則依作品來源與傳統命名；兩者分類角度不同，因此一首樂府詩也可以同時屬於古體詩。

## 古詩（古體詩）

古體詩又稱古詩、古風，是相對於唐代成熟的近體詩而言的詩體。它不受近體詩嚴格的字數、句數、平仄與對仗規則限制，篇幅、句式和用韻較有彈性；但並非完全沒有規律，仍常押韻，也會運用節奏、對偶等技巧。

古體詩的發展源遠流長，包括漢魏古詩、文人樂府以及後世仿古之作。閱讀時可以留意長短句的節奏、換韻方式、敘事與抒情如何交錯，以及作品如何藉日常生活、歷史人物或自然景物寄託情感。

### 常見作品

- **《[古詩十九首](https://zh.wikisource.org/wiki/%E5%8F%A4%E8%A9%A9%E5%8D%81%E4%B9%9D%E9%A6%96)》**：東漢末年文人五言詩的代表。作品多寫遊子思鄉、思婦懷人、人生短促與離別無常，語言淺近而情意深長。常見篇目有〈行行重行行〉、〈迢迢牽牛星〉、〈涉江采芙蓉〉。
- **曹操〈[短歌行](https://zh.wikisource.org/wiki/%E7%9F%AD%E6%AD%8C%E8%A1%8C_(%E6%9B%B9%E6%93%8D))〉**：以宴飲歌詠起興，抒發求賢若渴、希望延攬人才以成就大業的心情。篇中引用《詩經》語句，將個人抱負與時代局勢結合。
- **曹操〈[觀滄海](https://zh.wikisource.org/wiki/%E8%A7%80%E6%BB%84%E6%B5%B7)〉**：登碣石山觀海，描寫海水、山島、草木與日月星漢，借宏闊景象展現胸襟。此詩常作為四言古詩的代表閱讀。
- **陶潛〈[飲酒](https://zh.wikisource.org/wiki/%E9%A3%B2%E9%85%92%E4%BA%8C%E5%8D%81%E9%A6%96)〉其五**：從結廬、飲酒、採菊與見南山等日常景象，寫出遠離塵俗、安頓心境的體會；「採菊東籬下，悠然見南山」尤為常見。
- **李白〈[將進酒](https://zh.wikisource.org/wiki/%E5%B0%87%E9%80%B2%E9%85%92_(%E6%9D%8E%E7%99%BD))〉**：以飲酒勸歌的樂府舊題展開，抒發人生短促、珍惜豪情與自信不凡；句式奔放，情緒由感嘆推向高昂。它同時是古體詩，也屬於沿用樂府舊題的作品。

## 樂府詩

「樂府」原是古代掌管音樂、採集民間歌謠並整理、配樂演唱的機構。後來「樂府」也用來稱呼樂府機構所採集、製作或保存的歌辭；再往後，文人即使不為實際演唱而作，也會沿用樂府舊題創作，因此「樂府詩」既可能指早期的歌辭，也可能指後世仿樂府題意創作的詩。

樂府作品和音樂、歌唱及社會生活關係密切，題材多樣，常見戰爭徭役、婚姻愛情、勞動生活、民間疾苦與宴飲詠懷。部分作品敘事性強，善於透過人物對話、情節推展與具體細節呈現處境；形式並不單一，也不代表每首都能確定配樂演唱。

### 常見作品

- **〈陌上桑〉：** 漢樂府敘事詩，寫採桑女子羅敷拒絕使君調戲，並以誇飾描寫她的美貌與機智，呈現女性的自尊和拒絕權勢的勇氣。
- **〈長歌行〉：** 漢樂府，借園中葵與秋日萬物感嘆時光流逝，勸人珍惜年少、及時努力；「少壯不努力，老大徒傷悲」是最常見的名句。
- **〈孔雀東南飛〉：** 長篇敘事詩，敘述焦仲卿、劉蘭芝因家庭壓迫而被迫分離，最後雙雙殉情。作品刻畫人物細緻，也呈現婚姻自主與家族倫理之間的衝突，常與《木蘭詩》並稱「樂府雙璧」。
- **〈木蘭詩〉：** 北朝樂府民歌，敘述木蘭代父從軍、立功歸家。作品以明快的敘事、反覆與對比塑造木蘭既勇敢又眷戀日常生活的形象，也描寫戰事、歸途與家人團聚。
- **曹操〈短歌行〉：** 文人沿用樂府舊題創作的代表。作品以宴飲詠懷，寄託延攬人才、建功立業的願望；題名雖源於樂府傳統，內容已發展出鮮明的個人政治抱負。
- **杜甫〈兵車行〉：** 唐代新題樂府代表，透過送別場面及人物陳述，揭露頻繁征戰給百姓與家庭帶來的痛苦，將樂府敘事傳統用來關懷現實。

## 古詩與樂府詩比較總表

| 比較面向 | 古詩（古體詩） | 樂府詩 |
| --- | --- | --- |
| 分類角度 | 主要按詩體形式區分，與格律較嚴整的近體詩相對 | 主要按音樂機構、歌辭來源或沿用樂府題目的創作傳統區分 |
| 形成與發展 | 源自先秦、漢魏詩歌傳統，唐代近體詩成熟後，「古體」常用來指不依近體格律寫作的詩 | 漢代樂府機構採集、整理或製作歌辭；後世文人沿用舊題或另創新題繼續寫作 |
| 格式與音樂 | 句數、篇幅、字數、平仄較自由，常押韻但不必遵守近體詩的固定格律 | 形式多樣，早期與歌唱、音樂關係密切；後世樂府作品不一定實際入樂 |
| 常見題材 | 抒情、詠物、懷古、宴飲、山水與人生感懷等 | 民間生活、戰爭徭役、婚姻愛情、社會疾苦，也包括文人詠懷 |
| 常見表現方式 | 可偏抒情、寫景或議論，依作者與作品而異 | 常見敘事、人物對話與情節鋪展，但並非每首都以敘事為主 |
| 代表作品 | 《古詩十九首》、曹操〈觀滄海〉、陶潛〈飲酒〉其五、李白〈將進酒〉 | 〈陌上桑〉、〈長歌行〉、〈孔雀東南飛〉、〈木蘭詩〉、杜甫〈兵車行〉 |
| 兩者關係 | 是依形式界定的詩體範圍 | 是依來源、題目或創作傳統界定的類別；不少樂府詩採古體形式，兩者可以重疊 |

## 判讀提醒

1. **先看分類依據：** 問「是不是古體詩」，著重句式、格律與詩體；問「是不是樂府詩」，則要看作品是否來自樂府歌辭傳統或沿用樂府題目。
2. **不要把樂府等同民歌：** 漢樂府保存了不少民間歌辭，但後世文人樂府也是重要部分。
3. **不要把樂府等同可演唱：** 早期樂府與音樂關係密切，後世沿用舊題的作品不一定有曲調或實際演唱。
4. **一首作品可能兼具兩種身分：** 例如李白〈將進酒〉採古體形式，又沿用樂府舊題；分析時可分別說明其詩體與題目傳統。
