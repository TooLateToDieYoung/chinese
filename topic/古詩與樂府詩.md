# 古詩與樂府詩

> 古詩與樂府詩，兩者合稱為「漢代文學雙璧」（一說「漢代文學雙葩」）

## 古詩（古體詩）

> 雖然「擬樂府」、「新樂府」屬於廣義的樂府詩，但其仍可同時具備古詩的特色。

古體詩又稱古詩、古風，是相對於唐代成熟的近體詩而言的詩體。它不受近體詩嚴格的字數、句數、平仄與對仗規則限制，篇幅、句式和用韻較有彈性；但並非完全沒有規律，仍常押韻，也會運用節奏、對偶等技巧。

古體詩的發展源遠流長，包括漢魏古詩、文人樂府以及後世仿古之作。閱讀時可以留意長短句的節奏、換韻方式、敘事與抒情如何交錯，以及作品如何藉日常生活、歷史人物或自然景物寄託情感。

### 常見作品

- **《[古詩十九首](https://zh.wikisource.org/wiki/%E5%8F%A4%E8%A9%A9%E5%8D%81%E4%B9%9D%E9%A6%96)》**：東漢末年文人五言詩的代表。作品多寫遊子思鄉、思婦懷人、人生短促與離別無常，語言淺近而情意深長。常見篇目有〈行行重行行〉、〈迢迢牽牛星〉、〈涉江采芙蓉〉。
- **曹操〈[短歌行](https://zh.wikisource.org/wiki/%E7%9F%AD%E6%AD%8C%E8%A1%8C_(%E6%9B%B9%E6%93%8D))〉**：以宴飲歌詠起興，抒發求賢若渴、希望延攬人才以成就大業的心情。篇中引用《詩經》語句，將個人抱負與時代局勢結合。
- **曹操〈[觀滄海](https://zh.wikisource.org/wiki/%E8%A7%80%E6%BB%84%E6%B5%B7)〉**：登碣石山觀海，描寫海水、山島、草木與日月星漢，借宏闊景象展現胸襟。此詩常作為四言古詩的代表閱讀。
- **陶潛〈[飲酒](https://zh.wikisource.org/wiki/%E9%A3%B2%E9%85%92%E4%BA%8C%E5%8D%81%E9%A6%96)〉**：組詩借飲酒與田園景物抒寫隱居生活，表現對世俗名利的淡泊；其中「採菊東籬下，悠然見南山」最為人熟知。
- **陶潛〈[歸園田居](https://zh.wikisource.org/wiki/%E6%AD%B8%E5%9C%92%E7%94%B0%E5%B1%85)〉**：組詩寫辭官歸隱後的田園生活，描繪耕作、村居與自然景物，表達遠離仕途、回歸本性的自在。
- **陳子昂〈[登幽州臺歌](https://zh.wikisource.org/wiki/%E7%99%BB%E5%B9%BD%E5%B7%9E%E8%87%BA%E6%AD%8C)〉**：登臺懷古，感嘆前代賢者已逝、後世知音未至，抒發懷才不遇與知音難覓的孤寂。
- **杜甫「[三吏三別](https://zh.wikipedia.org/wiki/%E4%B8%89%E5%90%8F%E4%B8%89%E5%88%AB)」**：包括〈新安吏〉、〈石壕吏〉、〈潼關吏〉和〈新婚別〉、〈垂老別〉、〈無家別〉，描寫戰亂中的徵兵與離別，呈現百姓承受的苦難及詩人的深切關懷。
- **李白〈[將進酒](https://zh.wikisource.org/wiki/%E5%B0%87%E9%80%B2%E9%85%92_(%E6%9D%8E%E7%99%BD))〉**：以飲酒勸歌的樂府舊題展開，抒發人生短促、珍惜豪情與自信不凡；句式奔放，情緒由感嘆推向高昂。它同時是古體詩，也屬於沿用樂府舊題的作品。
- **李白〈[古風](https://zh.wikisource.org/wiki/%E5%8F%A4%E9%A2%A8_(%E6%9D%8E%E7%99%BD))〉**：組詩多借古題與歷史意象諷喻現實，批判權貴與時弊，也寄託詩人的理想和抱負。

## 樂府詩

> 題名常以「歌」、「行」、「引」、「吟」、「曲」、「操」、「弄」結尾

「樂府」原是古代掌管音樂、採集民間歌謠並整理、配樂演唱的機構。後來「樂府」也用來稱呼樂府機構所採集、製作或保存的歌辭；再往後，文人即使不為實際演唱而作，也會沿用樂府舊題創作，因此「樂府詩」既可能指早期的歌辭，也可能指後世仿樂府題意創作的詩。

樂府作品和音樂、歌唱及社會生活關係密切，題材多樣，常見戰爭徭役、婚姻愛情、勞動生活、民間疾苦與宴飲詠懷。部分作品敘事性強，善於透過人物對話、情節推展與具體細節呈現處境；形式並不單一，也不代表每首都能確定配樂演唱。

### 常見作品

- **〈[上邪](https://zh.wikisource.org/wiki/%E4%B8%8A%E9%82%AA)〉**：漢樂府民歌，女子以山崩、江水枯竭等不可能發生的景象立誓，表明對愛情的忠貞；語氣直率熱烈，善用誇張和排比。
- **〈[陌上桑](https://zh.wikisource.org/wiki/%E6%97%A5%E5%87%BA%E6%9D%B1%E5%8D%97%E9%9A%85%E8%A1%8C_(%E8%B1%94%E6%AD%8C%E7%BE%85%E6%95%B7%E8%A1%8C))〉**：漢樂府敘事詩，寫採桑女子羅敷拒絕使君調戲，並以誇飾描寫她的美貌與機智，呈現女性的自尊和拒絕權勢的勇氣。
- **〈[長歌行](https://zh.wikisource.org/wiki/%E9%95%B7%E6%AD%8C%E8%A1%8C_(%E6%BC%A2%E6%A8%82%E5%BA%9C))〉**：漢樂府，借園中葵與秋日萬物感嘆時光流逝，勸人珍惜年少、及時努力；「少壯不努力，老大徒傷悲」是最常見的名句。
- **〈[孔雀東南飛](https://zh.wikisource.org/wiki/%E5%8F%A4%E8%A9%A9%E7%82%BA%E7%84%A6%E4%BB%B2%E5%8D%BF%E5%A6%BB%E4%BD%9C)〉**：長篇敘事詩，敘述焦仲卿、劉蘭芝因家庭壓迫而被迫分離，最後雙雙殉情。作品刻畫人物細緻，也呈現婚姻自主與家族倫理之間的衝突，常與〈木蘭詩〉並稱「樂府雙璧」。
- **〈[木蘭詩](https://zh.wikisource.org/wiki/%E6%9C%A8%E8%98%AD%E8%A9%A9)〉**：北朝樂府民歌，敘述木蘭代父從軍、立功歸家。作品以明快的敘事、反覆與對比塑造木蘭既勇敢又眷戀日常生活的形象，也描寫戰事、歸途與家人團聚。
- **〈[白頭吟](https://www.arteducation.com.tw/shiwenv_4769631b7247.html)〉**：漢樂府古辭，以女子口吻寫得知情人變心後決意分離，並以「願得一心人，白頭不相離」表達對專一情感的期盼。
- **班婕妤〈[怨歌行](https://zh.wikisource.org/wiki/%E6%80%A8%E8%A9%A9_(%E7%8F%AD%E5%A9%95%E5%A6%A4))〉**：以團扇入秋後被收起為喻，寫女子遭冷落、恩情中斷的哀怨；常以「秋扇見捐」概括這類失寵的感傷。
- **曹操〈[短歌行](https://zh.wikisource.org/wiki/%E7%9F%AD%E6%AD%8C%E8%A1%8C_(%E6%9B%B9%E6%93%8D))〉**：文人沿用樂府舊題創作的代表。作品以宴飲詠懷，寄託延攬人才、建功立業的願望；題名雖源於樂府傳統，內容已發展出鮮明的個人政治抱負。
- **曹丕〈[燕歌行](https://zh.wikisource.org/wiki/%E7%87%95%E6%AD%8C%E8%A1%8C_(%E6%9B%B9%E4%B8%95))〉**：以秋夜思婦懷念遠行丈夫為主題，細寫離別後的孤寂與綿長思念；全篇七言，常被視為現存最早的完整七言詩之一。
- **杜甫〈[麗人行](https://zh.wikisource.org/wiki/%E9%BA%97%E4%BA%BA%E8%A1%8C)〉**：描寫楊氏姊妹春遊曲江的盛況，藉華服珍饈與奢華排場諷刺權貴驕縱，並暗寓繁華表象下的政治危機。
- **杜甫〈[兵車行](https://zh.wikisource.org/wiki/%E5%85%B5%E8%BB%8A%E8%A1%8C)〉**：描寫百姓送親人出征的悲痛，透過徵夫的訴說控訴連年戰事與無休徵役，呈現戰爭帶給百姓的苦難。
- **杜甫〈[茅屋為秋風所破歌](https://zh.wikisource.org/wiki/%E8%8C%85%E5%B1%8B%E7%82%BA%E7%A7%8B%E9%A2%A8%E6%89%80%E7%A0%B4%E6%AD%8C)〉**：寫秋風破屋、夜雨漏床的困境，進而推想到天下寒士，表達願使眾人都能安居的願望。
- **李白〈[長干行](https://zh.wikisource.org/wiki/%E9%95%B7%E5%B9%B2%E8%A1%8C%E4%BA%8C%E9%A6%96)〉**：以女子自述的口吻，從青梅竹馬、婚後生活寫到丈夫遠行後的思念，細膩呈現真摯情感與離別愁緒。
- **白居易〈[琵琶行](https://zh.wikisource.org/wiki/%E7%90%B5%E7%90%B6%E8%A1%8C)〉**：藉琵琶女的身世與音樂描寫，連結詩人遭貶江州的失意，感嘆彼此身世相似，也流露對其處境的同情。
- **白居易〈[長恨歌](https://zh.wikisource.org/wiki/%E9%95%B7%E6%81%A8%E6%AD%8C)〉**：以唐玄宗與楊貴妃的愛情及安史之亂為背景，敘寫兩人的歡愛、離散與無盡思念，兼具歷史感慨和浪漫想像。


## 古詩與樂府詩比較總表

| 比較面向 | 古體詩 | 樂府詩 |
| --- | --- | --- |
| 分類角度 | 主要按詩體形式區分，與格律較嚴整的近體詩相對 | 主要按音樂機構、歌辭來源或沿用樂府題目的創作傳統區分 |
| 形成與發展 | 源自先秦、漢魏詩歌傳統，唐代近體詩成熟後，「古體」常用來指不依近體格律寫作的詩 | 漢代樂府機構採集、整理或製作歌辭；後世文人沿用舊題或另創新題繼續寫作 |
| 格式與音樂 | 句數、篇幅、字數、平仄較自由，常押韻但不必遵守近體詩的固定格律 | 形式多樣，早期與歌唱、音樂關係密切；後世樂府作品不一定實際入樂 |
| 常見題材 | 抒情、詠物、懷古、宴飲、山水與人生感懷等 | 民間生活、戰爭徭役、婚姻愛情、社會疾苦，也包括文人詠懷 |
| 常見表現方式 | 可偏抒情、寫景或議論，依作者與作品而異 | 常見敘事、人物對話與情節鋪展，但並非每首都以敘事為主 |
| 兩者關係 | 是依形式界定的詩體範圍 | 是依來源、題目或創作傳統界定的類別；不少樂府詩採古體形式，兩者可以重疊 |

## 判讀提醒

1. **先看分類依據：** 問「是不是古體詩」，著重句式、格律與詩體；問「是不是樂府詩」，則要看作品是否來自樂府歌辭傳統或沿用樂府題目。
2. **不要把樂府等同民歌：** 漢樂府保存了不少民間歌辭，但後世文人樂府也是重要部分。
3. **不要把樂府等同可演唱：** 早期樂府與音樂關係密切，後世沿用舊題的作品不一定有曲調或實際演唱。
4. **一首作品可能兼具兩種身分：** 例如李白〈將進酒〉採古體形式，又沿用樂府舊題；分析時可分別說明其詩體與題目傳統。
