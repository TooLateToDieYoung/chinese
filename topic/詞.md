# 詞

## 詞特色

1. 又稱曲子詞、詩餘、長短句，原是配合燕樂歌唱的歌辭，後逐漸發展為獨立的文學體裁。

2. 依詞調填寫：每首詞依詞牌規定句數、字數、平仄與押韻，句式長短不一；同一詞牌也可能有不同體式。

3. 詞牌是曲調名稱，不等同作品題目。詞牌後可另加題目，如蘇軾〈念奴嬌・赤壁懷古〉。

4. 篇幅常分小令、中調、長調，但各家對字數界線的分法不盡相同；詞常分片（又稱闋），不少作品分為上下兩片，但片數也可能不同。
    > 常見分法以全詞字數計：小令五十八字以內，中調五十九至九十字，長調九十一字以上。這是便於概說的分類，詞籍與研究者的界線偶有差異。

## 詞流變

- 詞體在隋唐燕樂發展中逐漸形成，初期多為配樂歌辭；至晚唐、五代，文人填詞逐漸興盛。
- 北宋詞體發展成熟，題材與表現方式擴大；南宋詞既有抒寫家國興亡的作品，也有講究音律與語言鍛鍊的創作。
- 詞在宋代最為興盛，後世仍持續創作，明清詞亦各有發展。
- 婉約、豪放是常見的詞風概括，並非嚴格的派別界線；同一作者也可能寫出不同風格的作品。

## 常見詞風

### 詞學稱號補充

- **詞之正宗**：「正宗」是後世詞論的評價，並非唯一固定的分類。清代戈載《宋七家詞選》稱周邦彥詞「最為詞家之正宗」；周邦彥擅長音律、格律與鋪敘，後世也常以「詞中老杜」推重其地位。
    > 婉約乃詞之正統；豪放屬詞之變格。
- **詞帝**：李煜常被後世稱為「詞帝」。這是對其詞作成就的尊稱；他的作品由宮廷生活的華麗轉向亡國後的深沉哀痛，拓展了詞的抒情境界。
    > 王國維《[人間詞話](https://zh.wikisource.org/wiki/%E4%BA%BA%E9%96%93%E8%A9%9E%E8%A9%B1)》：「詞至李後主而眼界始大，感慨遂深，遂變伶工之詞而為士大夫之詞。」又說：「尼采謂：『一切文學，余愛以血書者。』後主之詞，眞所謂以血書者也。」前者指出李煜使詞的境界與抒情深度有所拓展；後者以「血書」形容其詞情感真切深沉。

| 詞風 | 特色 | 常見代表 |
| :-: | :-- | :-- |
| 婉約 | 多寫兒女情思、離愁別緒與生活感受，語言含蓄細膩；也能寄託深沉情感。 | 柳永、李清照 |
| 豪放 | 題材較廣，常寫家國抱負、歷史感慨與人生議論，風格較開闊。 | 蘇軾、辛棄疾 |

## 作品舉隅

以下按主要創作時期列舉常見名篇，並非窮盡所有詞作。

### 唐、五代

- **溫庭筠〈[菩薩蠻](https://zh.wikisource.org/wiki/%E8%8F%A9%E8%96%A9%E8%A0%BB_(%E6%BA%AB%E5%BA%AD%E7%AD%A0))〉**：以細密筆法描寫女子妝容與春愁，辭采華美、意象繁富，是晚唐詞的重要代表。
- **李璟〈[攤破浣溪沙・秋恨](https://zh.wikisource.org/wiki/%E6%94%A4%E7%A0%B4%E6%B5%A3%E6%BA%AA%E6%B2%99_(%E6%9D%8E%E7%92%9F))〉**：由荷殘、香消寫深秋景象，再以「細雨夢回雞塞遠」寄託對遠人的思念，意境清婉含蓄。
- **李煜〈[相見歡・無言獨上西樓](https://zh.wikisource.org/wiki/%E7%9B%B8%E8%A6%8B%E6%AD%A1_(%E6%9D%8E%E7%85%9C))〉**：以深院、梧桐與缺月寫孤寂，將離愁比作剪不斷、理還亂的絲緒。
- **李煜〈[浪淘沙令](https://zh.wikisource.org/wiki/%E6%B5%AA%E6%B7%98%E6%B2%99%E4%BB%A4)〉**：從簾外雨聲、春意將盡寫到夢回故國，層層展現亡國後的悔恨與哀愁。
- **李煜〈[虞美人](https://zh.wikisource.org/wiki/%E8%99%9E%E7%BE%8E%E4%BA%BA_(%E6%9D%8E%E7%85%9C))〉**：由春花秋月引出故國之思，以「一江春水向東流」比喻無盡愁緒，抒發亡國後的哀痛。

### 北宋

- **晏殊〈[浣溪沙](https://zh.wikisource.org/wiki/%E6%B5%A3%E6%BA%AA%E6%B2%99_(%E6%99%8F%E6%AE%8A))〉**：由春日宴飲、夕陽與歸燕感嘆時光流逝，「無可奈何花落去，似曾相識燕歸來」寫出對流年消逝的惆悵。
- **范仲淹〈[漁家傲・秋思](https://zh.wikisource.org/wiki/%E6%BC%81%E5%AE%B6%E5%82%B2_(%E8%8C%83%E4%BB%B2%E6%B7%B9))〉**：描寫秋日邊塞的荒寒景象與戍守將士的思鄉之情，也流露守邊責任未了、難以歸家的矛盾。
- **柳永〈[雨霖鈴・秋別](https://zh.wikisource.org/wiki/%E9%9B%A8%E9%9C%96%E9%88%B4_(%E6%9F%B3%E6%B0%B8))〉**：以秋日送別為主題，從餞別場面寫到別後想像，運用景物烘托離愁，是婉約詞與慢詞的代表作。
- **柳永〈[望海潮](https://zh.wikisource.org/wiki/%E6%9C%9B%E6%B5%B7%E6%BD%AE_(%E6%9F%B3%E6%B0%B8))〉**：鋪寫杭州的湖山形勝、市井繁華與節日景象，展現詞作描寫都市風物的能力。
- **歐陽修〈[蝶戀花・庭院深深深幾許](https://zh.wikisource.org/wiki/%E8%9D%B6%E6%88%80%E8%8A%B1_(%E6%AD%90%E9%99%BD%E4%BF%AE))〉**：以深院、楊柳、簾幕與暮春景色烘托閨中人的孤寂，情景交融，含蓄婉轉。
- **歐陽修〈[踏莎行・候館梅殘](https://zh.wikisource.org/wiki/%E8%B8%8F%E8%8E%8E%E8%A1%8C_(%E6%AD%90%E9%99%BD%E4%BF%AE))〉**：由旅途春景寫到離別相思，以「平蕪盡處是春山，行人更在春山外」收束，將思念寄託於層疊遠山。
- **張先〈[天仙子・送春](https://zh.wikisource.org/wiki/%E5%A4%A9%E4%BB%99%E5%AD%90_(%E5%BC%B5%E5%85%88))〉**：由春夜景物寫到年華流逝，「雲破月來花弄影」以動態字眼寫出月下花影之美，是善用意象名句的代表。
- **秦觀〈[滿庭芳](https://zh.wikisource.org/wiki/%E6%BB%BF%E5%BA%AD%E8%8A%B3_(%E7%A7%A6%E8%A7%80))〉**：以「山抹微雲，天連衰草」開篇，借秋日景色寫離情，清麗含蓄，體現秦觀詞婉約深情的特色。
- **秦觀〈[踏莎行・郴州旅舍](https://zh.wikisource.org/wiki/%E8%B8%8F%E8%8E%8E%E8%A1%8C_(%E7%A7%A6%E8%A7%80))〉**：以「霧失樓臺，月迷津渡」營造迷濛幽深的意境，寄寓貶謫旅途中的孤獨與身世之感。
- **秦觀〈[鵲橋仙・七夕](https://zh.wikisource.org/wiki/%E9%B5%B2%E6%A9%8B%E4%BB%99_(%E7%A7%A6%E8%A7%80))〉**：借牛郎織女相會寫堅貞情愛，結尾指出真情不必拘泥朝夕相守，將傳統神話化為深刻的人生體會。
- **蘇軾〈[水調歌頭・明月幾時有](https://zh.wikisource.org/wiki/%E6%B0%B4%E8%AA%BF%E6%AD%8C%E9%A0%AD_(%E6%98%8E%E6%9C%88%E5%B9%BE%E6%99%82%E6%9C%89))〉**：中秋望月懷念弟弟，從人生聚散推及世事無常，最後以豁達心境祝願親人平安。
- **蘇軾〈[念奴嬌・赤壁懷古](https://zh.wikisource.org/wiki/%E5%BF%B5%E5%A5%B4%E5%AC%8C_(%E8%98%87%E8%BB%BE))〉**：借赤壁江山與周瑜的歷史形象追懷英雄，並感嘆自身際遇，氣象開闊，是豪放詞的代表作。
- **蘇軾〈[江城子・乙卯正月二十日夜記夢](https://zh.wikisource.org/wiki/%E6%B1%9F%E5%9F%8E%E5%AD%90_(%E8%98%87%E8%BB%BE)/%E6%B1%9F%E5%9F%8E%E5%AD%90_(%E4%B9%99%E5%8D%AF%E6%AD%A3%E6%9C%88%E4%BA%8C%E5%8D%81%E6%97%A5%E5%A4%9C%E8%A8%98%E5%A4%A2))〉**：追憶亡妻，從多年離隔寫到夢中重逢，以平實深情的語言抒發難以消退的哀思。
- **周邦彥〈[蘇幕遮](https://zh.wikisource.org/wiki/%E8%98%87%E5%B9%95%E9%81%AE_(%E5%91%A8%E9%82%A6%E5%BD%A5))〉**：描繪夏日荷塘與水風清涼，並由眼前景物牽出故鄉之思，章法細密而情景相生。

### 南宋

- **李清照〈[如夢令](https://zh.wikisource.org/wiki/%E5%A6%82%E5%A4%A2%E4%BB%A4_(%E6%9D%8E%E6%B8%85%E7%85%A7))〉**：回憶一次醉遊泛舟，藉「誤入藕花深處」及驚起鷗鷺的情景，呈現活潑明快的少女情趣。
- **李清照〈[聲聲慢・秋情](https://zh.wikisource.org/wiki/%E8%81%B2%E8%81%B2%E6%85%A2_(%E6%9D%8E%E6%B8%85%E7%85%A7))〉**：以疊字、秋景與冷清環境層層鋪寫晚年愁苦，情感深沉，是南渡後詞作的代表。
- **辛棄疾〈[破陣子・為陳同甫賦壯詞以寄之](https://zh.wikisource.org/wiki/%E7%A0%B4%E9%99%A3%E5%AD%90_(%E8%BE%9B%E6%A3%84%E7%96%BE))〉**：追憶沙場點兵與戰鬥場面，抒寫收復失地的壯志；結尾轉回現實，顯出理想難酬的悲慨。
- **辛棄疾〈[永遇樂・京口北固亭懷古](https://zh.wikisource.org/wiki/%E6%B0%B8%E9%81%87%E6%A8%82_(%E8%BE%9B%E6%A3%84%E7%96%BE))〉**：登亭懷古，借歷史人物與往事反思南宋局勢，表達對收復中原的關切及壯志未酬之憂。
- **辛棄疾〈[青玉案・元夕](https://zh.wikisource.org/wiki/%E9%9D%92%E7%8E%89%E6%A1%88_(%E8%BE%9B%E6%A3%84%E7%96%BE))〉**：描寫元宵燈市的熱鬧與繁華，再以人群中尋覓佳人的情景收束；結尾也常被解讀為不隨流俗、甘於寂寞的寄託。
- **辛棄疾〈[西江月・夜行黃沙道中](https://zh.wikisource.org/wiki/%E8%A5%BF%E6%B1%9F%E6%9C%88_(%E8%BE%9B%E6%A3%84%E7%96%BE))〉**：描寫夏夜鄉村的月色、稻香、蟬鳴與蛙聲，以清新明快的筆調呈現田園生活。
- **姜夔〈[揚州慢](https://zh.wikisource.org/wiki/%E6%8F%9A%E5%B7%9E%E6%85%A2)〉**：追記揚州經戰亂後的荒涼景象，將眼前衰敗與昔日繁華對照，寄託黍離之悲。

### 清

- **納蘭性德〈[長相思](https://zh.wikisource.org/wiki/%E9%95%B7%E7%9B%B8%E6%80%9D_(%E7%B4%8D%E8%98%AD%E6%80%A7%E5%BE%B7))〉**：寫詞人隨扈出關途中對故園的思念，以風雪聲與夢境襯托羈旅的孤寂。
- **納蘭性德〈[木蘭花令・擬古決絕詞](https://zh.wikisource.org/wiki/%E6%9C%A8%E8%98%AD%E8%8A%B1%E4%BB%A4_(%E7%B4%8D%E8%98%AD%E6%80%A7%E5%BE%B7))〉**：借女子口吻寫情感由親密轉為疏離，以「人生若只如初見」感嘆情意難以長久。
