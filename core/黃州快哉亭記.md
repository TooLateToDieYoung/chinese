# 黃州快哉亭記

> **文意懶人包：** 蘇轍先寫長江與快哉亭的壯闊景色，再借楚襄王、宋玉論風的故事指出：風本身沒有「雄風」「雌風」之分，真正使人感到快樂或憂愁的，是人的處境與心境。篇末以張夢得謫居而能自適為例，說明不被外物牽動，便能在不同環境中安頓自己。

原文可參閱維基文庫〈[黃州快哉亭記](https://zh.wikisource.org/wiki/%E9%BB%83%E5%B7%9E%E5%BF%AB%E5%93%89%E4%BA%AD%E8%A8%98)〉。

## 一、先認識作品

### 寫作背景

〈黃州快哉亭記〉是北宋蘇轍所作。元豐年間，蘇轍因兄長蘇軾受「烏臺詩案」牽連而謫居筠州；元豐六年（1083），他替謫居黃州的友人張夢得作此文。張夢得在住所西南建亭觀賞江流，蘇軾為亭題名「快哉」；蘇轍則藉亭名發揮，追問「快」究竟從何而來。

張夢得一般被認為是蘇軾〈記承天寺夜遊〉中的張懷民，但兩篇文章的名字寫法不同，閱讀時可知道兩者常被聯繫，不必把考證當成本文主旨。

文中的「黃州」是北宋齊安郡，約在今湖北黃岡一帶；「赤壁」指黃州附近的赤壁，不等同於三國赤壁之戰確切古戰場。文章關心的是長江景色、歷史想像與人的心境，不在考證地理位置。

### 文體與篇章安排

本文是「記」，表面記亭、記景，實際由景物生發議論，最後寄寓人生道理。文章不是先提出抽象道理，而是依次寫江勢、亭上所見、歷史遺跡、古人論風，最後才點明人的心境如何決定所感。這種由具體景物逐步推進到議論的安排，使說理有畫面、有情境。

## 二、全文脈絡：江勢、亭景、風典、心境

| 層次 | 內容 | 作用 |
| --- | --- | --- |
| 江勢開篇 | 寫長江出西陵、匯合支流後，流勢越發浩大 | 先建立宏闊的地理背景，帶出黃州江景 |
| 建亭觀江 | 交代張夢得建亭、蘇軾命名，描寫亭上可見的江流、風雲與山村 | 說明亭名「快哉」的眼前理由，並寫出景色雖變而人可從容觀賞 |
| 懷古論風 | 由赤壁周邊的三國遺跡，轉入楚襄王與宋玉談風的故事 | 將「快」從賞景推向歷史和人事，提出風無雌雄、人的遭遇有不同 |
| 心境作結 | 以張夢得謫居而不以謫為患，歸結「不以物傷性」 | 回答何以為快：外境不必完美，內心坦然便能自適 |

全篇可用一句話記住：**先寫江景之快，再寫懷古之快，最後指出真正的快不只在景，而在人的心境。**

## 三、逐段賞析

### 第一段：長江由峽出平，氣勢逐步展開

> 「江出西陵，始得平地，其流奔放肆大；南合湘、沅，北合漢、沔，其勢益張；至於赤壁之下，波流浸灌，與海相若。」

開篇從長江流域寫起。「西陵」指西陵峽；長江出峽後進入較開闊的平地，水流不再受峽谷拘束，於是「奔放肆大」。「肆」有放縱、展開之意，寫出江流舒展奔湧的氣勢。

接著寫長江南合湘水、沅水，北合漢水、沔水，支流匯入，江勢「益張」，也就是更加盛大。視線沿著江流推進，最後抵達赤壁之下，水勢浩蕩，彷彿與海相接。

第一段不是單純交代地理，而是先讓讀者感到江流的力量與尺度。後文亭上「舉目而足」之所以令人稱快，正因眼前所見連接著如此廣闊的天地。

### 第二段：亭上觀江，遠景盡收眼底

> 「清河張君夢得，謫居齊安，即其廬之西南為亭，以覽觀江流之勝；而余兄子瞻，名之曰快哉。」

「清河」是張夢得的郡望，「齊安」是黃州的別稱；「謫居」指因罪或政治原因被降職、安置在外地。「即」是就著、利用。「覽觀江流之勝」意為觀賞江流的美景。「子瞻」是蘇軾的字，亭名「快哉」由蘇軾所取。

幾句就交代了人物、處境、建亭原因與亭名由來。值得注意的是，亭主人身在謫居之地，卻建亭賞景；文章從一開始便把「困頓處境」與「能否自適」放在一起。

> 「蓋亭之所見，南北百里，東西一舍。」

「蓋」在此有推想、概說的語氣；「一舍」是古代行軍約三十里的距離。亭上視野南北約百里，東西也十分遼闊。數字不必當成精密測量，更重要的是讓人感到視野開展、天地廣大。

> 「濤瀾洶湧，風雲開闔。晝則舟楫出沒於其前，夜則魚龍悲嘯於其下。變化倏忽，動心駭目，不可久視。」

「開闔」是開展、聚合；「倏忽」是迅速變化。「濤瀾洶湧」寫江面的動勢，「風雲開闔」把天空也納入景物。「舟楫出沒」寫白日船隻時現時隱；「魚龍悲嘯」則是夜間江水聲勢的想像性描寫，不必當作真的看見魚龍。

這些句子不只寫「美」，也寫景色驚心動魄、變化迅疾，幾乎使人「不可久視」。亭上所見並非一幅靜止的畫，而是一個不斷變動、充滿力量的世界。

> 「今乃得玩之几席之上，舉目而足。」

「乃」帶有「如今竟能」的意味；「几席」指亭中的几案席位；「舉目而足」是抬眼便能飽覽、心願已足。前句寫江勢洶湧、令人震動，這裡轉為人在亭中從容觀賞：自然景物雖然猛烈，觀景者卻能安坐其間。

「今乃」暗示亭的作用：原本遼遠、變化難測的江景，因有亭而成為可安坐賞玩的風景。亭不只是一座建築，也成了人與天地之間的觀看位置。

> 「西望武昌諸山，岡陵起伏，草木行列，煙消日出，漁夫樵父之舍，皆可指數，此其所以為快哉者也。」

「岡陵」是山岡丘陵；「行列」寫草木如列隊般整齊；「指數」是可以一一指出、數清楚。霧散日出，山勢、草木、漁夫樵父的房舍都清晰可見。

至此，作者明確說出一層「快」：亭上的視野開闊，遠景清楚，眼耳都得到滿足。但接下來文章不會停在「風景好所以快」，而是追問人們對風景的感受，是否真的只由風景本身決定。

### 第三段：歷史遺跡與「雄風」故事，提出快憂之辨

> 「至於長洲之濱，故城之墟，曹孟德、孫仲謀之所睥睨，周瑜、陸遜之所騁騖，其流風遺跡，亦足以稱快世俗。」

「長洲」是江中或江邊的長形沙洲；「故城之墟」是舊城遺址。「曹孟德」是曹操的字，「孫仲謀」是孫權的字；「周瑜」「陸遜」則是東吳名將。「睥睨」在此指雄視、爭逐之意；「騁騖」是縱橫馳騁。

黃州赤壁一帶讓人聯想到三國時期曹操、孫權及周瑜、陸遜等人的歷史。「流風遺跡」指前人留下的聲名與遺蹟。這些懷古景物能讓一般人感到痛快，因為登高望遠、追想英雄事蹟，本來就容易引起興奮與感慨。

不過，這裡的「世俗」帶出普通人的觀看方式；作者接下來要借一段古代故事，進一步檢驗「同一陣風，是否人人都感到快」。

> 「昔楚襄王從宋玉、景差於蘭臺之宮，有風颯然至者，王披襟當之，曰：『快哉此風！寡人所與庶人共者耶？』」

這裡化用宋玉〈風賦〉中的故事。楚襄王與宋玉、景差在蘭臺宮中遊賞，忽然有風吹來；楚襄王敞開衣襟迎風，稱讚「快哉此風」，並問這是不是自己與百姓共同享有的風。

「颯然」是風聲或風勢突然到來的樣子；「披襟」是敞開衣襟；「當之」是迎著它；「寡人」是古代君王自稱；「庶人」是平民百姓。楚襄王表面在問風是否人人共享，實際上也顯出他把風的享受看作君王特權。

> 「宋玉曰：『此獨大王之雄風耳，庶人安得共之？』玉之言，蓋有諷焉。」

宋玉回答，這是只屬於大王的「雄風」，百姓怎麼能共同享有？「諷」是委婉勸諫、諷刺。宋玉順著君王的話說，卻也暗示君王與百姓處境不同：同樣的風，對生活優渥的君王是享受，對勞苦的百姓未必如此。

> 「夫風無雌雄之異，而人有遇不遇之變；楚王之所以為樂，與庶人之所以為憂，此則人之變也，而風何與焉？」

「遇不遇」指境遇得意或失意；「何與焉」是與它有什麼關係。蘇轍指出，風本身沒有雌雄之分，變的是人的境遇：楚王能悠閒享風，百姓卻可能為生活奔忙，因此同一陣風引起不同感受。

這是全文的思想轉折。蘇轍並非說景物不重要，而是提醒讀者：感受不只由外物決定，也受人的身分、遭遇和內心狀態影響。風沒有改變，感受卻可能不同；既然如此，「快」也不必只靠外在條件供給。

### 第四段：張夢得不以謫為患，落實「快」的道理

> 「士生於世，使其中不自得，將何往而非病？使其中坦然，不以物傷性，將何適而非快？」

「使」是假使；「其中」指人的內心；「自得」是自我安適；「病」在此不是疾病，而是困苦、不快；「適」是到、往。「不以物傷性」是說不因外物或遭遇而損傷自己的本性、心志。

這兩句用一問一答般的對照，收束前面的風之譬喻：

- 若內心不能自安，走到哪裡都可能覺得困苦。
- 若內心坦然，不被外物牽著走，到哪裡都可能找到安適。

「將何往而非病」「將何適而非快」都是反問，語氣有力，將文章由亭上的景色推到普遍的人生處境。

> 「今張君不以謫為患，竊會計之餘功，而自放山水之閒，此其中宜有以過人者。」

「不以謫為患」是沒有把貶謫當作唯一的憂患；「竊」在此有私下、利用之意；「會計」指處理財計、帳務的公務；「餘功」是公務以外的空閒；「自放」是放懷自適；「宜有以過人」是想必有超過常人的地方。

張夢得並非沒有遭遇困境，而是在公務之餘建亭賞景，沒有讓「被貶」完全佔據自己的心。蘇轍因此推想，他內在一定有過人之處。這裡的「快」不是忘記現實、假裝無事，而是即使處境受限，仍能為自己保留欣賞生活的空間。

> 「將蓬戶甕牖，無所不快；而況乎濯長江之清流，挹西山之白雲，窮耳目之勝以自適也哉！」

「蓬戶甕牖」指以蓬草為門、以破甕為窗，形容簡陋居所；「濯」是洗滌、親近；「挹」是汲取、迎取；「窮耳目之勝」是盡情享受耳目所能感受的美景。

既然張夢得能在困窘中不失自適，即使住在簡陋房屋也能找到快樂；更何況如今可以親近長江清流、迎取西山白雲，盡情欣賞自然美景。這是層層遞進：由簡陋生活也能自適，推到擁有江山勝景時更可從容享受。

> 「不然，連山絕壑，長林古木，振之以清風，照之以明月，此皆騷人思士之所以悲傷憔悴而不能勝者。烏睹其為快也哉？」

「連山絕壑」是連綿山脈與深谷；「振之以清風，照之以明月」是讓清風吹拂、明月照耀；「騷人思士」指多愁善感、懷才不遇或思慮深重的文人；「憔悴」是精神困頓、面容消瘦；「不能勝」是承受不了；「烏睹」是怎麼看得出、哪裡還談得上。

同樣的山、谷、樹木、清風與明月，有些人能欣賞，有些人卻因憂思而更加悲傷。若不是內心坦然，眼前再美的景色也可能成為愁緒的觸媒。末句以反問收尾，回扣全文：景物本身不保證快樂，能否「快」仍與人的心境有關。

## 四、典故、歷史指涉與文化語彙

讀古文時，可分辨「典故」是借用古代人物或故事，「歷史指涉」是提及具體人物事件，「文化語彙」則是具有背景知識的詞語，不必把每個詞都當成典故。

| 文句／詞語 | 出處或背景 | 在文中的作用 |
| --- | --- | --- |
| 西陵 | 長江三峽之一的西陵峽 | 交代長江出峽後由峽谷進入平地，展開江勢。 |
| 湘、沅、漢、沔 | 長江流域及其支流水系 | 寫支流匯入、江勢擴大的地理背景。 |
| 赤壁 | 黃州附近的赤壁地景；本文不以考證赤壁之戰戰場為主 | 由江景轉入三國歷史想像。 |
| 清河張君夢得 | 張夢得是亭主人，謫居齊安；一般常與張懷民相聯繫 | 將文章的議論落在一位具體的謫居者身上。 |
| 亭名「快哉」 | 由蘇軾命名 | 成為蘇轍全文追問「快從何來」的題眼。 |
| 曹孟德、孫仲謀 | 曹操、孫權的字 | 連結赤壁周邊與三國爭戰、英雄往事。 |
| 周瑜、陸遜 | 東吳將領，曾在三國歷史中以軍事行動著稱 | 與曹操、孫權並列，寫出當地的歷史厚度。 |
| 楚襄王、宋玉、景差、蘭臺 | 化用宋玉〈風賦〉故事 | 引出「雄風」與「庶人之風」的說法，供蘇轍翻轉觀點。 |
| 「快哉此風」 | 楚襄王迎風稱快 | 表面讚風，實際顯示君王以為享受是特權。 |
| 「雄風」 | 宋玉以雄風指楚王專享的風 | 蘇轍指出風沒有雌雄之別，讓議論回到人與境遇。 |
| 「騷人思士」 | 「騷人」承接《楚辭》屈原以來的文人稱呼，後泛指詩人文士 | 點出同樣的自然景物也可能引發文人的愁苦。 |
| 「不以物傷性」 | 與先秦道家重視不為外物所役、保全本性的思想相通 | 說明文章所講的不是控制風景，而是不讓外物支配內心。 |

## 五、文章如何層層說理

### 1. 由大江到一亭，視野逐步收束

文章先從長江出西陵、匯合支流寫起，尺度極大；再落到赤壁附近的江流；接著聚焦在張夢得的小亭；最後更深入人的「其中」——內心。讀者的視線由天地江河逐步收回到人的心境，文章也由寫景自然過渡到說理。

### 2. 「快」字貫穿全文，意義逐步改變

| 「快」的層次 | 內容 |
| --- | --- |
| 景物之快 | 亭上可見浩蕩江流、山巒、白雲與日出。 |
| 懷古之快 | 追想曹操、孫權、周瑜、陸遜等歷史人物，滿足世俗懷古之情。 |
| 心境之快 | 即使謫居、身處簡陋，只要心中坦然、不以外物傷性，便能自適。 |

前兩層是具體經驗，最後一層才是作者要建立的道理。標題的「快哉」因此不只是在說風景漂亮。

### 3. 借宋玉故事，先立一說再翻轉

宋玉說楚王享有「雄風」，百姓不能共享；蘇轍接著說「風無雌雄之異」，把故事的說法翻轉過來。風一樣，人的際遇不同，感受才不同。這種先敘故事、再辨析其中道理的安排，比直接說教更有說服力。

蘇轍也沒有把宋玉的諷諫抹去：他承認君王與庶人的生活處境確實不同，但把焦點從「誰有資格享風」轉到「人的感受如何受到境遇影響」，再進一步追問人能否不被境遇完全支配。

### 4. 對偶與反問讓文章有節奏

- 「南合湘、沅，北合漢、沔」以方位對舉，寫支流匯合。
- 「晝則舟楫出沒於其前，夜則魚龍悲嘯於其下」以晝夜、江上江下對照，寫景物變化。
- 「使其中不自得……使其中坦然……」用相似句式對比兩種心境。
- 「將何往而非病？」「將何適而非快？」連續反問，語氣由分析走向結論。
- 「烏睹其為快也哉？」以反問收篇，讓讀者回想全篇的「快」到底從何而來。

### 5. 景物既是風景，也是論證材料

江風可以讓楚王稱快，也可能讓百姓無暇感受；清風明月可以是騷人愁思的背景，也可以是坦然者自適的資源。景物在文中不只是裝飾，而是一再證明「外物相同，人的感受會因處境和心境而異」。

## 七、帶著問題回讀

1. 第一段為什麼要從西陵峽一路寫到赤壁？江勢的尺度如何幫助讀者理解亭上的「快」？
2. 亭上「動心駭目」的景色，為什麼又能在「几席之上」從容欣賞？「今乃」帶出什麼轉變？
3. 宋玉說「雄風」時在諷刺什麼？蘇轍又如何把焦點由風轉到人？
4. 「使其中不自得」和「使其中坦然」兩句，分別描寫哪兩種人生狀態？
5. 作者稱讚張夢得不以謫為患，是否等於說被貶不值得難過？請從「不以物傷性」理解兩者差別。
6. 結尾的清風明月為何可能使「騷人思士」悲傷？這如何回扣全文主旨？

## 八、全篇收束

〈黃州快哉亭記〉表面寫江景與亭子，實際在問：同樣的風景，為什麼有人快、有人憂？蘇轍借楚襄王、宋玉論風的故事指出，外物本身沒有固定的情緒；人的遭遇、身分與內心，會影響如何感受它。

文章並不是要求人否認謫居的困難，也不是說只要心態好，所有問題就會消失。它肯定的是人在處境受限時，仍可保有觀看、感受與自我安頓的能力。江風、白雲可以是眼前可賞的風景，也可以提醒人不必把整個生命交給外在得失決定。
