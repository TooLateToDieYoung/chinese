# 前赤壁賦

> **文意懶人包：** 蘇軾與客人在赤壁月夜泛舟，先由美景與音樂得到快樂，再因歷史興亡與人生短暫陷入悲感；蘇軾接著借水月說明「變」與「不變」可以從不同角度觀看，最後把哲理落回眼前人人可共享的清風明月。全文不是叫人否認悲傷，而是帶讀者走過悲傷，找到重新安頓自己的方法。

原文可參閱維基文庫〈[前赤壁賦](https://zh.wikisource.org/wiki/%E5%89%8D%E8%B5%A4%E5%A3%81%E8%B3%A6)〉。

## 一、先認識作品

### 寫作背景

蘇軾因「烏臺詩案」於元豐三年（1080）謫居黃州。元豐五年（1082）七月十六日，他與友人泛舟遊覽黃州赤壁一帶，寫下〈前赤壁賦〉；同年十月又遊赤壁，寫〈後赤壁賦〉。

這裡的「赤壁」通常認為是黃州的赤鼻磯一帶，不是三國赤壁之戰的確切古戰場。蘇軾借眼前江山追想赤壁之戰，作品的重點在歷史想像與人生感受，不是考證戰場地點。

### 文體與說話方式

「賦」善於鋪陳景物、敘事抒情，也可以議論說理；本文是宋代散賦，兼有散文的自然流暢、韻文的節奏，以及主客問答的安排。

文中的「蘇子」和「客」可以當作兩個對話角色來讀，也可以理解為蘇軾內心不同想法的對話：客把失意、有限與無常說到極處，蘇子則不是簡單反駁，而是換個角度重新觀看。這種讀法有助理解全文，並不表示歷史上只有一位同行者。

## 二、全文脈絡：景、樂、悲、辯、喜

| 層次 | 內容 | 情緒與作用 |
| --- | --- | --- |
| 月夜泛舟 | 記時、遊江、賞月，寫江天開闊 | 由清幽景色帶出自在、超然的感受 |
| 飲酒而歌 | 主人因快樂而唱，唱出遙望「美人」的心意 | 快樂之中已藏著思念與理想不能即達的微愁 |
| 洞簫轉悲 | 客以洞簫和歌，簫聲哀怨，蘇子察覺氣氛改變 | 聲音成為情緒轉折，也引出「何為其然」 |
| 客憶英雄 | 客從曹操、赤壁之戰想到英雄不再，再想到自身渺小短暫 | 由歷史興亡推及個人生命，將悲情推至高點 |
| 蘇子論水月 | 以水、月說明變化與恆常，以清風明月作答 | 不是否認無常，而是指出觀看事物還有另一種尺度 |
| 舟中共適 | 客釋然，重新飲酒，眾人枕藉而眠，天色將明 | 情緒回到平和；哲理落實為共享當下的生活經驗 |

可用五個字記住全文：**景 → 樂 → 悲 → 辯 → 喜**。這不是情緒突然翻轉，而是由景生情、由情觸發思考，再由思考重新回到生活。

## 三、逐段賞析

### 第一段：清風明月，進入江天之境

> 「壬戌之秋，七月既望，蘇子與客泛舟遊於赤壁之下。」

開頭交代時間、人物、活動和地點，像簡潔的遊記。壬戌是宋神宗元豐五年（1082）；「既望」指農曆十五望日之後，本文通常解作十六日。時間很具體，接下來的感受卻逐漸超越日常。

> 「清風徐來，水波不興。」

「徐」寫風的輕柔，「不興」寫水面平靜。兩句短而舒緩，先為全篇定下安靜的節奏。

> 「舉酒屬客，誦《明月》之詩，歌《窈窕》之章。」

「屬」讀作 ㄓㄨˇ，是勸酒、請客人飲酒。這裡的《明月》通常指《詩經・陳風・月出》，《窈窕》通常指《詩經・周南・關雎》中的「窈窕淑女」。詩歌、飲酒與月夜相連，使遊宴帶有古典文化的回聲。

> 「少焉，月出於東山之上，徘徊於斗牛之間。白露橫江，水光接天。」

「少焉」是過了一會兒；「斗牛」是斗宿、牛宿兩個星宿，不是鬥牛。月亮緩緩升起，江面水氣與月光相接，「白露橫江，水光接天」把江與天寫成無邊的一體。視線由東山移向星空，再鋪展到整個江面，景物尺度逐步擴大。

> 「縱一葦之所如，凌萬頃之茫然。」

「一葦」形容小舟輕細如一片蘆葦；「縱」是任憑，「如」是往，「凌」是越過。小舟在萬頃江面上漂行，形成「舟小而天地大」的對照。

> 「浩浩乎如馮虛御風，而不知其所止；飄飄乎如遺世獨立，羽化而登仙。」

「馮虛」是凌空，「御風」是乘風；「遺世」是離開塵世，「羽化登仙」帶有道家成仙的想像。這不是說蘇軾真的成仙，而是寫人在江天之間彷彿脫離日常拘束。第一段以月夜實景，逐漸推向超然的想像，快樂達到高點。

### 第二段：歌聲裡的思念

> 「於是飲酒樂甚，扣舷而歌之。」

「扣舷」是敲著船舷打拍子。「樂甚」承接前段的自在，但歌詞很快透露出內心並非只有歡樂。

> 「桂棹兮蘭槳，擊空明兮泝流光。渺渺兮予懷，望美人兮天一方。」

「桂棹蘭槳」把船槳寫得香潔而美好；「空明」指清澈明亮的水面，「流光」指流動的月光；「泝」通「溯」，是逆流而上。「美人」表面可指思念的人，在楚辭傳統中也常寄託理想、知音或所思慕的對象。歌聲從眼前月光轉到遠方的「美人」，讓前段的仙境感添上一層求而不得的惆悵。

### 第三段：洞簫使歡樂轉為悲涼

> 「客有吹洞簫者，倚歌而和之。」

客人隨著歌聲吹簫。「和」讀作 ㄏㄜˋ，是應和。簫聲不是裝飾性的背景，而是把歌中的微愁放大，成為全篇第一個明顯轉折。

> 「其聲嗚嗚然，如怨如慕，如泣如訴；餘音裊裊，不絕如縷。」

「如怨如慕，如泣如訴」連用四個相近的感受，讓讀者彷彿聽見簫聲中的委屈、依戀和哭訴；「不絕如縷」把悠長而纖細的餘音比作快要斷掉的絲線。

> 「舞幽壑之潛蛟，泣孤舟之嫠婦。」

「嫠婦」是寡婦。簫聲彷彿能使深谷潛蛟起舞，令孤舟寡婦落淚。這是極度誇張的通感式描寫：聲音被寫成能作用於生物、牽動人心的力量，不必解作真有蛟龍或某位寡婦在場。

### 第四段：客從赤壁想到生命有限

> 「蘇子愀然，正襟危坐而問客曰：『何為其然也？』」

「愀然」是神色變得嚴肅，「危坐」是端正坐好。蘇子從歡飲中的自在轉為認真聆聽，讓客人的悲意有機會完整說出。

> 「月明星稀，烏鵲南飛，此非曹孟德之詩乎？」

這兩句直接化用曹操〈短歌行〉「月明星稀，烏鵲南飛」。月夜眼前景色與古人詩句重疊，讓赤壁現場立刻進入三國歷史。

> 「西望夏口，東望武昌，山川相繆，鬱乎蒼蒼，此非孟德之困於周郎者乎？」

「夏口」「武昌」是長江沿岸的地名；「相繆」通「繚」，指山川盤繞交錯；「周郎」指周瑜。客看著江岸，想到曹操在赤壁之戰中受挫。黃州赤鼻磯並非赤壁之戰確切古戰場，但蘇軾借周遭地景觸發歷史聯想，正是文章的寫法。

> 「方其破荊州，下江陵，順流而東也，舳艫千里，旌旗蔽空。」

「方其」是當他正值；「下江陵」的「下」指攻下；「順流而東」是順長江向東進軍；「舳艫」指船隻首尾相接。客先把曹操軍隊寫得聲勢浩大，為下一句「而今安在哉」蓄勢：昔日的盛大越鮮明，今日消逝的感慨越深。

> 「釃酒臨江，橫槊賦詩，固一世之雄也，而今安在哉？」

「釃酒」是斟酒；「槊」是長矛。「橫槊賦詩」把武將與詩人的形象合在一起，寫曹操臨江飲酒、豪情作詩的氣概。這是對歷史人物的文學化描繪，不必視為某一部史書所記的單一事件。客的問題「而今安在哉」把懷古推向生命哲學：連一代英雄都已不在，個人又如何避免消逝？

> 「況吾與子漁樵於江渚之上，侶魚蝦而友麋鹿；駕一葉之扁舟，舉匏樽以相屬。」

「漁樵」是打魚、砍柴；「侶」「友」在此作意動用法，意為以魚蝦為伴、以麋鹿為友；「匏樽」是葫蘆製的酒器；「相屬」是互相勸酒。客將曹操的「舳艫千里」與自己的一葉小舟對照，把歷史英雄的盛大和眼前人的平凡並列。

> 「寄蜉蝣於天地，渺滄海之一粟。哀吾生之須臾，羨長江之無窮。」

「蜉蝣」朝生暮死，常用來比喻生命短促；「滄海一粟」是大海中的一粒米，比喻個體極其渺小。「須臾」是片刻。客以有限人生對照無盡長江，說出最直接的失落：人既短暫又渺小，因此羨慕江水長流。

> 「挾飛仙以遨遊，抱明月而長終。知不可乎驟得，託遺響於悲風。」

「飛仙」是道家仙人想像；「驟得」是突然得到；「遺響」是餘音。客渴望與仙人遨遊、抱著明月長存，卻知道不可能立刻實現，於是把心願寄託在悲涼的簫聲中。這段將懷古、生命短暫、求仙幻想和現實無奈層層推進，構成全篇情緒最低點。

### 第五段：蘇子以水月改變觀看角度

> 「蘇子曰：『客亦知夫水與月乎？逝者如斯，而未嘗往也；盈虛者如彼，而卒莫消長也。』」

蘇子沒有說客的悲傷不合理，而是先請客看水與月。「逝者如斯」化用《論語・子罕》孔子在川上感嘆時光流逝的「逝者如斯夫，不舍晝夜」；「盈虛」指月亮的圓缺。

水看似不斷流走，但江水仍在；月亮看似有盈有虧，整個月體並沒有真的因圓缺而增減。這不是否認眼前變化，而是提醒讀者：同一件事可從流動的個別時刻看，也可從持續存在的整體看。

> 「蓋將自其變者而觀之，則天地曾不能以一瞬；自其不變者而觀之，則物與我皆無盡也，而又何羨乎？」

「曾不能以一瞬」是連一瞬間也不能保持不變。「變」的角度看，天地萬物每一刻都在改變；「不變」的角度看，萬物與我又同在綿延不絕的宇宙中。蘇子不是要選擇其中一種而否定另一種，而是把兩種觀點都保留下來：人確實有限，但生命也參與了更大的自然流轉。

### 第六段：清風明月是人人可享的「無盡藏」

> 「且夫天地之間，物各有主，苟非吾之所有，雖一毫而莫取。」

「物各有主」是說各物有其所屬；不是自己的財物，就不取分毫。這句先承認現實生活中的界線與分際，讓後面的「取之無禁」不是鼓吹任意佔有。

> 「惟江上之清風，與山間之明月，耳得之而為聲，目遇之而成色，取之無禁，用之不竭。」

清風可聽，明月可看；它們不必據為己有，卻能被每個人感受。「無禁」「不竭」寫自然之美不因分享而減少，恰與客所羨慕的「長江無窮」呼應：人不必成仙，也能在有限生命裡親近不盡的自然。

> 「是造物者之無盡藏也，而吾與子之所共適。」

「造物者」指創造、化育萬物的自然力量；「無盡藏」是取用不盡的寶藏；「適」是享用、適意。文章的答案不是追求私人占有或永生，而是發現天地間有可與人共享的美。哲理因此回到感官經驗：聽風、看月，便是此刻可以實踐的生活。

### 結尾：情緒真正回到人間

> 「客喜而笑，洗盞更酌，肴核既盡，杯盤狼籍。相與枕藉乎舟中，不知東方之既白。」

客人「喜而笑」，表示他被說服或心情舒展；「更酌」是再斟酒，「肴核」是菜餚果品，「狼籍」是散亂的樣子，「枕藉」是交錯枕靠。「東方既白」寫天色已亮，也收回開頭的月夜。

結尾沒有讓人物高談玄理，而是讓他們繼續飲酒、吃完菜餚、在船中相倚而眠。這份平凡的親近，正是前段「共適」的具體呈現。天亮不只是時間推移，也象徵情緒從悲感中走出；但歷史無常與人生有限並沒有因此消失，而是被放回更寬廣的觀看之中。

## 四、典故、語源與歷史指涉

閱讀時要分清楚：**典故**是借用古代人物、事件或文本；**歷史指涉**是指向具體歷史事件；**意象或修辭**則可能只是在創造畫面，不一定有唯一出處。

| 文句／詞語 | 出處或背景 | 在文中的作用 |
| --- | --- | --- |
| 《明月》之詩 | 通常指《詩經・陳風・月出》 | 讓月夜遊宴帶有《詩經》的古典聲音。 |
| 《窈窕》之章 | 通常指《詩經・周南・關雎》「窈窕淑女」 | 以古詩歌點出宴飲、歌唱的文化情境。 |
| 「桂棹兮蘭槳」 | 化用《楚辭・九歌・湘君》「桂櫂兮蘭枻」一類語句 | 以香木舟具營造高雅、清美的歌辭語境。 |
| 「美人」 | 《楚辭》常以美人寄託所思慕的人或理想；本文不限定唯一所指 | 讓歌聲由眼前景色轉向遠方思慕，含有理想難即的意味。 |
| 「馮虛御風」 | 《莊子・逍遙遊》引列子「御風而行」的故事；本文承襲乘風遨遊的道家想像，不一定是逐字引用 | 把泛舟感受寫得像凌空飛行，表現精神暫時超越日常拘束。 |
| 「羽化而登仙」「飛仙」 | 道家、神仙思想中的成仙想像 | 表現乘風超脫、長生不死的願望；客其實明白願望難以實現。 |
| 「月明星稀，烏鵲南飛」 | 曹操〈短歌行〉 | 由月夜引出曹操與三國往事，連結眼前赤壁和歷史記憶。 |
| 「孟德之困於周郎」 | 赤壁之戰；孟德是曹操的字，周郎指周瑜 | 點明客懷古的核心事件，並引出英雄盛衰的感慨。 |
| 「破荊州，下江陵，順流而東」 | 曹操南下、進軍長江流域的歷史背景 | 鋪寫曹操戰勢盛大，為「而今安在哉」作對比。 |
| 「舳艫千里，旌旗蔽空」 | 對曹軍船隊與軍容的文學化鋪陳 | 以誇張寫昔日聲勢，使盛與衰的落差更強。 |
| 「釃酒臨江，橫槊賦詩」 | 曹操臨江飲酒、持矛賦詩的英雄形象；常見於後世懷古敘述 | 將武功和文才合為一體，突出英雄氣概及其終將消逝。 |
| 「蜉蝣」 | 古典文學中常用以象徵短暫生命；《詩經・曹風・蜉蝣》也以蜉蝣起興 | 突顯生命短促；本文不一定是在引用《詩經》某一句。 |
| 「滄海之一粟」 | 以大海與一粒米作比的譬喻 | 表現個體在浩瀚宇宙中的渺小，不必指定為某一部經典的直接引文。 |
| 「逝者如斯」 | 化用《論語・子罕》「逝者如斯夫，不舍晝夜」 | 先承認時光流逝，再藉水的連續性開展不同觀點。 |
| 「盈虛者如彼」 | 以月亮盈虧作比 | 指月相變化；和江水一起構成全文「變／不變」的哲理核心。 |
| 「造物者之無盡藏」 | 「造物者」是古典哲理中創生萬物的自然力量；「無盡藏」是取用不竭的寶藏譬喻 | 把江風山月視為可共享的自然資源，不是某段經文的逐字引用。 |

另外，「斗牛」是星宿名稱，「嫠婦」是寡婦，「匏樽」是葫蘆酒器；這些是詞義或文化背景，不必都列作典故。「舞潛蛟、泣嫠婦」是誇張的聲音效果，也不必認定為真實事件。

## 五、文章如何寫得如此動人

### 1. 主客問答：讓抽象思考變成戲劇

若一開始就直接講「人生無常，要豁達」，文章會像說教。蘇軾先讓客人把悲傷說完整，再由蘇子回應。讀者因此先經歷疑惑與低潮，才跟著換角度思考。客人的悲與蘇子的答，都可以看作人心中真實存在的聲音。

### 2. 景、情、理層層相生

| 景物或聲音 | 引出的情感／思考 |
| --- | --- |
| 清風、水波、月出、白露 | 覺得自由、開闊，彷彿脫離日常 |
| 桂棹、月光、遠方美人 | 快樂中浮現思念與理想 |
| 洞簫、幽壑、孤舟 | 感傷加深，轉入歷史與生命問題 |
| 長江與明月 | 先引出短暫與無窮的對照，再成為理解變化的例子 |
| 清風與明月 | 哲理回到可以親身感受、可以共享的美 |

### 3. 對比讓情緒有力量

- **小舟與萬頃：** 人很小，天地很大。
- **曹操的舳艫千里與「一葉扁舟」：** 歷史英雄的盛大對照當下個人的平凡。
- **人生須臾與長江無窮：** 有限生命對照自然長流。
- **變與不變：** 同一江水既在流逝，也持續存在；同一輪月既有盈虧，也仍是月。
- **悲風與清風：** 風先伴隨簫聲呈現悲意，後來則成為可以欣賞、共享的自然之美。

對比不是要判定哪一邊「才是真的」，而是讓讀者發現：觀看角度不同，感受與結論也會不同。

### 4. 聲音描寫把人帶進現場

「清風徐來」「水波不興」讀來平緩；到了「如怨如慕，如泣如訴」，句式反覆，情緒也變得纏綿。簫聲的「餘音裊裊，不絕如縷」不只描寫聲音，也像客人心中牽繫不斷的愁緒。文章用節奏讓情緒被讀者「聽見」。

### 5. 鋪陳與整句形成賦體節奏

文章常以相似句式並列，例如「如怨如慕，如泣如訴」、「耳得之而為聲，目遇之而成色」。鋪陳讓景物與情感逐步擴大，整齊句式則帶來音韻和節奏；但它又不受嚴格駢文格律限制，因此兼有散文的自在與賦體的聲情。

## 七、帶著問題回讀

1. 第一段已經寫到「羽化而登仙」，客為什麼還會悲傷？試找出歌詞中的「美人」和簫聲如何預先埋下情緒轉折。
2. 客為什麼先寫曹操「固一世之雄」，再問「而今安在哉」？兩句之間的盛衰對比如何推進他的生命感？
3. 蘇子談「變」與「不變」，是說萬物永遠不變嗎？請用水與月分別解釋兩種觀看角度。
4. 「清風明月」為什麼能回答客的悲傷？它如何把抽象哲理變成人人能經驗的生活？
5. 結尾「不知東方之既白」與開頭的月夜形成什麼照應？人物情緒回到原點了嗎，還是已經有所不同？

## 八、全篇收束

〈前赤壁賦〉從一次夜遊寫起，經過歌聲、簫聲、懷古與問答，最後回到江上清風明月。它承認英雄會消逝、生命有期限，也提醒人不必只用「我能活多久」衡量生命的價值：人在有限時間裡，仍能感受自然、與人分享、在變化中找到安頓。

所以，這篇文章的「曠達」不是沒有悲傷，也不是用一句「想開一點」把痛苦抹去；而是先看見悲傷，再擴大自己的觀看尺度，最後重新珍惜此刻可以共同享有的生活。
